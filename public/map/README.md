# 中国本地底图

将一张**中国地形渲染图**放入此目录并命名为 `china-physical.png`，项目将自动用它替换默认的全球卫星图，加载速度极快且只显示中国区域。

## 图片要求

| 属性 | 要求 |
|:--|:--|
| **文件名** | `china-physical.png` |
| **投影** | 等距圆柱投影（Equirectangular / Geographic） |
| **范围** | 覆盖中国全境（约 东经73°–135°，北纬18°–55°） |
| **格式** | PNG（推荐）或 JPG |
| **分辨率** | 建议 ≥ 4096×2048 像素，越高放大越清晰 |
| **风格** | 物理地形图 / 高程渲染图（带山脉阴影最佳） |

## 图片来源建议

在百度/Google 搜索以下关键词可找到合适的图片：

- `中国地形渲染图`
- `China physical map equirectangular`
- `中国地形图 圆柱投影 高清`
- `China elevation map tile`

下载后裁剪至中国范围、转换为等距圆柱投影即可。

## 没有本地图片时的表现

如果此文件不存在，系统会自动使用 **Cesium 默认的 Bing Maps 卫星图**作为底图（全球范围）。此时加载速度受网络影响。
