# 中国古代3D历史地图 — 产品需求文档 (PRD)

> **版本**: v2.0  
> **一句话定义**: 一个 Web 端的 3D 中国历史地图，根据输入时间自动切换到对应朝代的疆域与地名，渲染真实地形（山川河流高原平原），支持四季变化，并允许用户自由绘制彩色箭头来标注势力动向。

## 1. 产品概述

### 1.1 要解决的问题

历史爱好者、教师、学生在回顾古代战役时，往往只能对着平面静态地图想象。缺少一个工具能够：

- 直观看到**真实 3D 地形**（山脉有多高、河流怎么流、关口有多险）
- 根据**输入年份自动切换**到对应朝代的地图（不用手动去找"东汉疆域图"）
- 感受**季节/气候**对战役的影响（冬天长江会不会结冰、秋天草原是否便于行军）
- **自由绘制**势力行军路线（不同颜色代表不同势力，箭头表示方向）

### 1.2 一句话总结

> 输入年份/战役名 → 自动切换到对应朝代疆域 → 在 3D 地形上自由标注彩色箭头 → 回顾战役过程。

## 2. 功能清单

### F1. 3D 地形渲染

- 以 3D 地球/平面方式展示中国及周边地区地形
- 地形包含：
  - **山脉**：秦岭、太行、昆仑、天山、横断、大兴安岭、祁连、南岭、武夷、长白等
  - **高原**：青藏高原、云贵高原、黄土高原、内蒙古高原
  - **平原**：华北平原、长江中下游平原、关中平原、东北平原
  - **盆地**：四川盆地、塔里木盆地、准噶尔盆地、柴达木盆地
- **水系**：
  - 主要河流：黄河、长江、淮河、珠江、黑龙江、澜沧江等
  - 重要湖泊：洞庭湖、鄱阳湖、太湖、青海湖
  - 大运河（显示对应朝代的实际路线）
- 地形可旋转、缩放、倾斜（标准 3D 相机操作）

### F2. 时间轴 / 朝代切换

- 用户输入**年份**（如 `-260` 或 `208`）或**年号**（如 `贞观元年`）或**战役名**（如 `赤壁之战`）
- 系统自动匹配对应朝代，并加载：
  - 该朝代的**疆域边界**
  - 该朝代的**主要地名/城市/关隘**
  - 该时期的**河流/湖泊/海岸线**（处理历史变迁）
- 支持通过**时间轴滑块**快速浏览不同朝代
- 朝代切换时带**过渡动画**

### F3. 四季变化

- 提供**春 / 夏 / 秋 / 冬**四个季节按钮，一键切换
- 视觉效果：
  - 春：绿色植被，河流水量正常
  - 夏：深绿植被，河流水量充沛
  - 秋：黄/红色植被，水量减少
  - 冬：北方积雪（按纬度+海拔自动计算雪线），河流冰封效果
- 可联动战役时间（如赤壁之战发生在冬季，默认展示冬季）

### F4. 箭头绘制工具（用户自由标注）

- 用户在工具栏选择箭头**颜色**（预设多色，也可自定义）
- 用户在工具栏选择箭头**样式**（实线箭头、虚线箭头、宽箭头等）
- 用户在地图上**点击创建节点**，形成直线或折线箭头路径
- 每条箭头可以：
  - 附带**文字标签**（如"曹操军 20万"）
  - **拖拽修改**节点位置
  - **删除**整条箭头或单个节点
- 支持一个场景中同时存在多条不同颜色的箭头，分别代表不同势力
- 箭头随地图缩放/旋转保持正确的地理位置

### F5. 地图标注与图层管理

- 图层开关：
  - ☑ 地形（3D 高程）
  - ☑ 疆域边界
  - ☑ 河流湖泊
  - ☑ 地名/关隘
  - ☑ 势力箭头（用户绘制的）
- 点击地点/关隘弹出信息卡（古今地名对照）

### F6. 辅助功能

- **搜索定位**：输入古地名或今地名，相机飞行至该位置
- **截图导出**：导出当前视角的高清截图（PNG）
- **视角收藏**：保存常用视角（书签功能）
- **URL 分享**：分享链接包含当前时间、视角参数

## 3. 用户使用流程

### 典型流程：回顾赤壁之战

```
1. 打开网站 → 看到 3D 中国地形，默认显示当前朝代（可设置）
2. 在搜索框输入"赤壁之战" 或 "208年"
3. 系统自动切换至东汉末年疆域，相机飞到长江中游
4. 3D 地形清晰展示：长江天险、两岸丘陵、乌林与赤壁的相对位置
5. 点击季节按钮切到"冬" → 江面有雾气效果
6. 在工具栏选择 🔵 蓝色箭头 → 代表曹操军
   在地图上点击：许昌 → 南阳 → 襄阳 → 江陵 → 乌林（折线自动生成）
7. 选择 🔴 红色箭头 → 代表孙刘联军
   在地图上点击：夏口 → 赤壁（直线箭头）
8. 给箭头添加标签："曹操军 20万"、"孙刘联军 5万"
9. 缩放、旋转视角，从不同角度观察地形与行军路线的关系
10. 截图保存，完成回顾
```

## 4. 技术方案建议

### 4.1 推荐技术栈

| 层次 | 技术 | 说明 |
|:--|:--|:--|
| **3D 地图引擎** | CesiumJS | 原生支持全球 3D 地形、矢量图层、时间动态 |
| **前端框架** | React + TypeScript | 生态成熟，有 `resium` 库封装 Cesium |
| **UI 组件库** | Tailwind CSS + shadcn/ui | 快速构建控制面板 |
| **状态管理** | Zustand | 轻量，管理图层/箭头/时间状态 |
| **地理计算** | Turf.js | 箭头路径计算、距离测量 |
| **地形数据** | Cesium World Terrain（免费）+ 自建 DEM | 基础地形 |
| **历史疆域数据** | GeoJSON（来自 CHGIS / 自建） | 各朝代边界 |

### 4.2 为什么选 CesiumJS

- ✅ 开箱即用的 3D 地球 + 地形
- ✅ 原生支持 GeoJSON 加载（疆域边界）
- ✅ 强大的标注/绘制 API（箭头、标签）
- ✅ 内置时间系统（CZML），天然适合朝代切换动画
- ✅ 免费使用（Apache 2.0 开源）
- ✅ 支持移动端

### 4.3 箭头绘制实现思路

```
用户点击地图 → 获取经纬度坐标 → 创建节点
连续点击 → 生成节点序列 → 连成 Polyline
Polyline 末端自动添加箭头图标（朝最后一段方向）
颜色/样式由用户工具栏选择决定
添加标签：在 Polyline 中点放置 Billboard（文字气泡）
```

使用 CesiumJS 的 `PolylineCollection` + 自定义箭头材质，或直接使用 `Entity` + `polyline` + `billboard` 组合实现。

## 5. 数据来源

### 5.1 地形数据（免费）

| 数据 | 来源 | 分辨率 |
|:--|:--|:--|
| 全球 DEM | Cesium World Terrain（ion 免费配额） | 30m |
| 中国高精度 DEM | 地理空间数据云 (gscloud.cn) | 30m |

> 地形数据使用**现代**高程即可。古代地形变化主要在河流/海岸线，可通过矢量图层修正标注，无需重建古代 DEM。

### 5.2 历史疆域与地名数据

| 数据 | 来源 | 说明 |
|:--|:--|:--|
| 历史疆域边界 | Harvard CHGIS | 覆盖前221–1911年，Shapefile 可转 GeoJSON |
| 历史地名坐标 | CHGIS | 含时间属性，可按年份筛选 |
| 细化时期（三国等） | 自行手绘 GeoJSON | 参考谭其骧《中国历史地图集》 |
| 关隘/要塞 | 自建数据集 | 手动整理经纬度 |

### 5.3 河流历史变迁

- 黄河历代改道路线：参考水利史文献，手动整理 6 条主要古河道
- 大运河路线：隋唐 vs 元明清两套路线

## 8. 风险与注意事项

| 风险 | 应对 |
|:--|:--|
| 历史疆域数据不完整 | 优先做好秦/汉/三国/唐/宋/明/清 7 个核心朝代；细分时期（如十六国）后续慢慢加 |
| CesiumJS 入门曲线陡 | 先用官方 Sandcastle 跑通 Demo，再集成到 React |
| 3D 在手机端性能差 | 低端设备降级为 2D 俯视模式 |
| 箭头绘制交互复杂 | 先做最简单的"点击生成直线箭头（两点）"，后续再扩展到折线 |
| 黄河改道数据难找 | 先按现代河道渲染，标注"示意"，后续逐步修正 |
